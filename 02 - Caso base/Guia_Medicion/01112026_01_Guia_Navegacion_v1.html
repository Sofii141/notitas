2Una sola vez, antes de la primera sesión

  1. Abrir una terminal en Repositorio/CAMEIA-lite y traer lo último: git pull.
  2. Instalar pytest: pip install pytest. Comprobar: python -m pytest -k t01 (debe fallar: la función está vacía).
  3. Leer las 24 tareas de TAREAS.md una vez, solo para revisar que se entienden.
  4. Congelar: git tag congelado-notitas-v1 y git push origin congelado-notitas-v1.
  5. Sortear: python sorteo.py <semilla> > registro/sorteo_<semilla>.txt. Anotar la semilla en la hoja Sesiones.
  6. Imprimir (o tener abiertas) las fichas de las tareas que el sorteo dejó en línea base.

3Cada tarea, en orden

  1. Tomar la siguiente tarea de la lista de línea base del sorteo y abrir su ficha.
  2. Llenar la parte 1 de la ficha (incluido el pronóstico).
  3. Abrir el enunciado en TAREAS.md, arrancar el cronómetro, commit tNN: inicio.
  4. Programar en pareja en backend/notitas/tNN.py, sin IA, cambiando de rol cada 15 min.
  5. Cuando pasan las visibles: parar, commit tNN: terminado, llenar la parte 2.
  6. Correr las ocultas, retrabajo si aplica, codewalk: llenar la parte 3.
  7. Pasar los números a Medicion por caso en la bitácora.

Al terminar todas

python "07 - Analisis/Scripts/resumen_medicion.py" --html llena la sección 6 del PDF de entrega.
