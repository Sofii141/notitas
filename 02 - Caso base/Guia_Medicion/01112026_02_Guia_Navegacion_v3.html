3El sorteo (una sola vez)

No eligen tareas: eligen un número cualquiera (semilla) y el programa reparte con cupos fijos (línea base 5 S · 4 M · 1 L; agente 5 S · 6 M · 1 L; 2 M de repuesto).

git tag congelado-notitas-v1 → git push origin congelado-notitas-v1 → python sorteo.py <semilla> > registro/sorteo_<semilla>.txt

4Al terminar la línea base

Copien las medidas a la bitácora, escribiendo Línea base en la columna Condición (en los ciclos: Ciclo 1 o Ciclo 2), y corran, todo en una línea:
python "07 - Analisis/Scripts/resumen_medicion.py" "05 - Ciclos y bitacora/31102026_01_Bitacora_v3.xlsx" --html "09 - Control de entrega/31102026_01_Punto_Control_v3.html"
