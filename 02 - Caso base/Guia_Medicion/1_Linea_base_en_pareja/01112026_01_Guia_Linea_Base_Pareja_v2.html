1Qué es

El "antes": ustedes dos programan juntos, sin IA, las 10 tareas que el sorteo dejó en línea base. Con estos números se compara después el trabajo con el agente.

Reglas

Nada de IA (ni ChatGPT, ni autocompletado con IA en el editor). La documentación de Python sí se puede usar. Un solo computador: uno escribe (conductor) y el otro revisa y guía (navegante); cambian cada 15 min. No abrir backend/tests/ocultas antes de terminar.

2Antes de la primera tarea

  1. Terminal en Repositorio/CAMEIA-lite: git pull y pip install pytest.
  2. Hojear TAREAS.md solo para ver que se entiende, sin pensar ni comentar soluciones. Si aún no está hecho: congelar (git tag congelado-notitas-v1, git push origin congelado-notitas-v1) y sortear (python sorteo.py <semilla> > registro/sorteo_<semilla>.txt).
  3. Llenar una fila en la hoja Sesiones (fecha, participantes, IA usada: ninguna, semilla).
  4. Desactivar el autocompletado con IA del editor, si lo tiene.

3Cada tarea

  1. Tomar la siguiente tarea de la línea Orden para hacerlas de la línea base en el sorteo y abrir su ficha en Fichas/.
  2. Parte 1: quién empieza conduciendo y pronóstico.
  3. Abrir el enunciado en TAREAS.md, arrancar cronómetro, git commit --allow-empty -m "tNN: inicio".
  4. Programar en backend/notitas/tNN.py hasta que pasen las visibles; commit tNN: terminado. Parte 2.
  5. Correr las ocultas, retrabajo si aplica y codewalk: parte 3 de la ficha.
  6. Pasar los números a Medicion por caso (columna Condición: exactamente Línea base, Ciclo 1 o Ciclo 2) en 05 - Ciclos y bitacora/31102026_01_Bitacora_v3.xlsx.

4Fichas (versión pareja)

Usen solo las 10 que el sorteo asigne a la línea base.
