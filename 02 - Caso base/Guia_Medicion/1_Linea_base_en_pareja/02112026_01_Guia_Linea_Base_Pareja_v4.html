1Cómo se trabaja

Los dos en llamada, sin IA. Cada tarea la escribe uno en su computador, y en la siguiente escribe el otro.

  • Conduce la misma persona toda la tarea; el otro participa activamente. Si no hay turnos parejos (número impar), uno conduce una más y se anota.
  • Antes de la primera tarea, hagan lo de la sección 4 de la Guía General. Se hace solo una vez.
  • Desactiven la IA del editor, como Copilot o el autocompletado con IA.

Qué pueden usar

Sí se puedeNo se puede
Documentación oficial de Python y de pytest. Google y Stack Overflow para dudas puntuales (por ejemplo, "cómo quitar tildes en Python"). Sus apuntes. ChatGPT, Gemini, Copilot, ni el resumen con IA que a veces muestra Google (ignórenlo). Buscar la solución completa de la tarea. Pedir ayuda a otra persona. Abrir backend/tests/ocultas o _Privado/ antes de tiempo.

Es la misma regla en todas las tareas. La única diferencia con agente: se permite OpenCode, y solo OpenCode. Si una búsqueda fue clave, anótenla en Observaciones.

2El ciclo de una tarea

  1. Elijan la tarea: la siguiente de Orden para hacerlas, en el archivo del sorteo (recuerden: primero una de cada tamaño si no alcanzan todas).
  2. Abran su ficha en Plantillas/. Quien conduce comparte pantalla y empieza a grabar.
  3. Sigan la ficha de arriba abajo. Trae todo: qué anotar y cada comando de git.
  4. Guarden la ficha llena en Respuestas/, o mándenme los datos por el chat.
  5. Cambien de conductor y sigan con la siguiente.

Qué hace cada comando de git

git pull trae lo que subió el otro.   git commit --allow-empty -m "t05: inicio" deja marcada la hora en que empezaron, aunque no haya cambios.   git add y git commit guardan su trabajo con un mensaje.   git push lo sube para que el otro lo tenga.

3Si algo sale mal

Qué pasóQué hacer
Hay que parar (comida, se cayó la llamada)Anoten la hora y los minutos en Pausas. Pueden seguir después; si cortan el video, empiecen otro.
Alguien abrió las ocultas antes de tiempoMarquen [C], dejen la tarea y usen una de repuesto del sorteo.
Olvidaron un datoDéjenlo vacío y márquenlo [N]. Nunca lo inventen.
git push dice "rejected"Corran git pull y luego git push otra vez. Si pide resolver un conflicto, paren y escríbanme.
Una tarea se está alargando muchoSigan, o anoten por qué la dejaron. No la borren ni cambien de conductor sin anotarlo.
Cualquier otra dudaPausen el cronómetro, anoten la pausa y pregúntenme.
