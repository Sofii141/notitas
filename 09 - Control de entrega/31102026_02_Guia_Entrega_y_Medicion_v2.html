3Congelar y sortear (una sola vez)

En la carpeta Repositorio/CAMEIA-lite, después de revisar las tareas:

  1. git pull y, si corrigieron alguna tarea, commit de esas correcciones.
  2. git tag -a congelado-notitas-v1 -m "Caso Notitas congelado" y git push origin congelado-notitas-v1. Desde aquí no se cambian ni las tareas ni las pruebas.
  3. Elegir una semilla (por ejemplo, la fecha de hoy: 31102026) y correr python sorteo.py 31102026 > registro/sorteo_31102026.txt.
  4. Commit y push del archivo del sorteo. Anotar la semilla en la hoja Sesiones.
  5. Pasar a la bitácora v3, columnas E y F, la condición y quién conduce cada tarea, según el sorteo.

4Paso a paso de cada sesión (para imprimir)

Al empezar (5 min)

  • git pull en el repositorio y en la carpeta de la entrega.
  • Línea base: cerrar OpenCode, Claude Code, ChatGPT y cualquier IA; en el editor, desactivar cualquier autocompletado con IA.
  • Empezar a grabar la pantalla, con el nombre de la sesión (p. ej. S01_01112026).
  • Bitácora v3, hoja Sesiones: fecha, hora de inicio, lugar y herramientas.

Por cada tarea (hoja Medicion por caso)

  1. M5 Pronóstico (columna H): cuántos minutos creen que les tomará, antes de abrir el enunciado.
  2. Inicio (columna I): abrir el enunciado en TAREAS.md, anotar la hora y hacer git commit --allow-empty -m "tNN: inicio".
  3. Trabajar en pareja: uno conduce y el otro navega, y cambian cada 15 min. python -m pytest -k tNN solo corre las visibles.
  4. Fin (columna J): cuando pasan las visibles, anotar la hora y hacer el commit tNN: terminado. La columna L (M1) se calcula sola.
  5. M2 Ocultas (columna M): python -m pytest backend/tests/ocultas -k tNN; anotar cuántas fallan.
  6. M3 Retrabajo (columna O): si corrigen, los minutos que tomó, con el commit tNN: retrabajo. Si no hubo, 0.
  7. M4 Codewalk (hoja Codewalk y columnas P y Q): cada uno le hace al otro las 5 preguntas, sin mirar el código. Máximo 5 min por persona.

Al terminar (10 min)

  • Hora de fin, interrupciones y nombre de la grabación en Sesiones.
  • Push de los commits de las tareas (main) y de la bitácora (documentacion).

5Cómo se llena el PDF con los datos

Desde la carpeta EntregaFinal-AGILES:

python "07 - Analisis/Scripts/resumen_medicion.py" "05 - Ciclos y bitacora/31102026_01_Bitacora_v3.xlsx" --html "09 - Control de entrega/31102026_01_Punto_Control_v3.html"

El script calcula las 5 métricas por tamaño desde los datos crudos, copia en la sección 6 las condiciones de las sesiones que ya tienen fecha y la tabla por tarea, y regenera el PDF. Si solo cambian texto del HTML (por ejemplo la sección 12), basta con python _Estilo/html_a_pdf.py "09 - Control de entrega/31102026_01_Punto_Control_v3.html".

Recálculo independiente

Quien no corrió el script calcula a mano la mediana de minutos de las tareas S y la compara con el PDF y con la hoja Resumen. Anota en Sesiones quién, qué cifra y si coincide. Esa cifra lleva [R].
